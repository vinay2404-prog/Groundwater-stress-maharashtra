# Groundwater Intelligence Dashboard PRD

## Objective
Build an interactive Tableau Public dashboard for Maharashtra groundwater observations from 2021 to 2025.

## Users
Water planners, analysts, and public viewers.

## Key Questions
1. What is the groundwater status of each district and taluka?
2. Which locations are over-extracting or stressed?
3. How have recharge, extraction, and stage changed over time?
4. What is the pre-monsoon vs post-monsoon difference?
5. Which districts have the largest extraction-recharge gap?
6. How are categories distributed?
7. Which districts rank highest?
8. What data is available for a selected location and year?

## Scope
Historical observations only. No forecasting.

## Data Source
sample-data/groundwater_data.csv

## Dashboards
1. Statewide Overview
2. District and Taluka Intelligence
3. Historical Trends
4. Risk and Criticality
5. Category and Ranking

## Branding
Dark navy theme with cyan, teal, green, yellow, orange, and red status colors.
